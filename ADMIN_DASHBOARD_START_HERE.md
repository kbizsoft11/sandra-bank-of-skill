## 🚀 Quick Access

### Access the Dashboard
```
URL: http://localhost:4200/admin/dashboard
Or: Click "Admin Dashboard" in sidebar menu
Role: Admin only
```

### API Base URL
```
Development: http://localhost:5000/api
Production: /api
```

### 6 API Endpoints
```
GET    /api/dashboard/admin/overview
GET    /api/dashboard/admin/charts
GET    /api/dashboard/admin/notifications
PUT    /api/dashboard/admin/notifications/:id/read
PUT    /api/dashboard/admin/notifications/:id/unread
GET    /api/dashboard/admin/recent-activities
```
