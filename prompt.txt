Implement Employee Dashboard Homepage

I am building a Skill Management / Workforce Skills platform inspired by Skills Base. I already have an existing application, so do not rebuild the project from scratch. First inspect the existing codebase, architecture, routing, authentication, reusable components, styling system, and API services. Then implement the Employee Dashboard homepage using the existing project conventions.

Objective

Create a modern, professional, responsive Employee Dashboard homepage that helps an employee quickly understand:

Their current skills
Their skill profile completion
Their skill gaps and development areas
Pending actions they need to complete
Their recent skill-related activity
Recommended learning or development opportunities
Their career growth / role readiness

The dashboard should feel like a real enterprise SaaS product, not a generic admin dashboard.

Dashboard Layout
1. Welcome Header

At the top of the dashboard, display:

Employee profile/avatar
Employee name
Job title
Department or team
A personalized greeting such as:
"Good morning, [Employee Name] 👋"
Supporting text:
"Here's an overview of your skills, development, and career growth."
Notification icon
Profile shortcut

Use the currently authenticated employee's data wherever available. Do not hardcode employee information.

2. Skills Summary Cards

Create a responsive row of summary cards.

Display:

Total Skills

Number of skills associated with the employee.

Verified Skills

Number of skills that have been verified.

Skills In Progress

Number of skills currently being assessed or developed.

Profile Completion

Percentage of the employee's skill profile that is complete.

Example:

Total Skills: 24
Verified Skills: 18
In Progress: 4
Profile Completion: 75%

The cards should be visually consistent and reusable.

If the backend API is not yet available, create a clean service/data abstraction so real API data can be connected later. Do not scatter hardcoded values throughout components.

Create a "My Skills" dashboard section showing the employee's most relevant or recently updated skills.

Each skill should display:

Verification status

Only show a limited number of skills on the homepage, such as 4–6.

Add a "View All Skills" button that navigates to the employee's complete skills page.

Create a section called:

"Skills to Develop"

Display tasks that require employee attention.

Complete an annual skills review

Responsive Layout

The dashboard must be fully responsive.

Desktop:

Use a multi-column dashboard layout.
Summary cards should appear in one row.
Main content can use a 2-column layout where appropriate.

Tablet:

Adjust cards into 2 columns.
Maintain readable spacing.

Mobile:

Stack all sections vertically.
Summary cards should use 1 or 2 columns depending on available width.
Ensure buttons and interactive elements are touch-friendly.
Avoid horizontal scrolling.
Design Requirements

The design should be:

Modern
Clean
Professional
Enterprise SaaS quality
Easy to scan
Accessible
Consistent with the existing application's design system

Do not introduce a completely different visual style from the rest of the application.

Reuse existing:

Colors
Typography
Buttons
Cards
Icons
Form components
Spacing system
Layout components
Sidebar/header components

If the project already has a design system or component library, use it instead of creating duplicate components.

Avoid excessive gradients, unnecessary animations, and overly decorative UI.

Use subtle hover states and transitions only where they improve usability.

Data and Architecture

Before implementation:

Inspect the existing frontend structure.
Identify the current employee authentication mechanism.
Identify how the logged-in employee is retrieved.
Inspect existing employee, skills, assessments, learning, and profile APIs.
Reuse existing API services and models where available.
Do not duplicate existing functionality.
Follow the project's existing naming and folder conventions.

Create reusable components where appropriate, for example:

DashboardSummaryCard
EmployeeSkillCard
SkillGapCard
PendingActionList
RecentActivityList
LearningRecommendationCard
CareerReadinessCard

Do not create unnecessary components if the existing architecture already provides equivalent reusable components.

API Integration

Use real backend APIs wherever they already exist.

If an API does not exist:

Do not modify unrelated backend functionality.
Create a clean frontend service abstraction or mock data layer.
Clearly structure the code so it can easily be replaced with a real API later.

Handle:

Loading states
Empty states
API errors
Unauthorized access
Missing employee data

Do not show a broken dashboard if one API fails. Individual sections should fail gracefully.

Navigation

The dashboard should provide navigation to:

My Skills
Skill Assessments
Development Plan
Learning
Career Path
Employee Profile

Use the application's existing routing system.

Do not create duplicate routes if these routes already exist.

Important Implementation Rules
First inspect the existing codebase before modifying anything.
Do not rewrite or restructure unrelated parts of the application.
Do not break existing functionality.
Reuse existing components and services whenever possible.
Use real authenticated employee data where available.
Do not hardcode user-specific data directly into the UI.
Keep API calls and business logic out of presentation components when the existing architecture supports services/state management.
Follow the existing project's coding style.
Ensure the implementation works on desktop, tablet, and mobile.
Add proper loading, error, and empty states.
Ensure there are no console errors or TypeScript errors.
Run the appropriate lint/build/test commands after implementation and fix any issues.
Expected Result

After implementation, the Employee Dashboard homepage should provide a clear employee-centric overview:

Welcome → Skill Summary → My Skills → Skill Gaps → Pending Actions → Recent Activity → Recommended Learning → Career Growth

The final result should feel like a polished employee skills-management dashboard suitable for a production SaaS platform.
